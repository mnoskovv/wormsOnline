# Червячки

Браузерная дуэль в духе Вормикса: два червяка, разрушаемая земля, 8 видов оружия, 5 карт.

**Играть:** https://mnoskovv.github.io/wormsOnline/

## По сети

1. Нажми «Создать игру» и отправь ссылку сопернику.
2. Соперник открывает ссылку, вводит имя и жмёт «В бой!».

Ничего устанавливать не нужно. Соединение идёт напрямую между браузерами (WebRTC через PeerJS), своего сервера нет.

## За одним компьютером

Кнопка «Хотсит — в бой!»: ходите по очереди. Можно открыть `index.html` двойным кликом, без интернета.

## Управление

| Действие | Клавиши |
|---|---|
| Ходить | ← → |
| Прыжок вперёд / назад | Enter / Backspace |
| Прицел | мышь |
| Зарядить и выстрелить | зажать пробел или ЛКМ, отпустить |
| Меню оружия | Tab или ПКМ |
| Быстрый выбор оружия | 1–8 |
| Таймер гранаты | 1–5, когда выбрана граната |

## Разработка

Чистый JS без сборки. Тесты: `node --test`.
